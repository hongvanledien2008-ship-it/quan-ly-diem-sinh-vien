# Quản lý điểm sinh viên – Streamlit

## Chạy trên máy
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Đăng lên Streamlit Community Cloud
1. Tạo repository trên GitHub.
2. Upload `app.py` và `requirements.txt` vào thư mục gốc repository.
3. Vào https://share.streamlit.io/ → Create app.
4. Chọn repository, branch `main`, main file path `app.py` → Deploy.
5. Sao chép URL ứng dụng để nộp bài.

Nhớ thay `[HỌ VÀ TÊN]` và `[MÃ SỐ SINH VIÊN]` ở cuối `app.py`.
